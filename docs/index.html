Question answering over FDA drug labels

A retrieval-augmented system answers questions using only excerpts from ~1,200 official FDA drug labels and cites them. Browse every evaluation question with the answer from each retrieval setup, the excerpts behind it, and an LLM judge's verdicts. Code and write-up on GitHub.

For information and research only. Not medical advice.

Data: openFDA drug labels (U.S. FDA public data). Built by Venkata Krishna Giri Koneru.
